# Midgard-Idle-English-Translation
Full English translation for Midgard Idle (play.midgardidle.ro)

<img width="1280" height="800" alt="screen1" src="https://github.com/user-attachments/assets/05a9f64f-b2f3-47a9-aea1-be03c32e3a23" />


Midgard Idle - English is a browser extension that fully translates the idle MMORPG Midgard Idle from Portuguese to English.

What gets translated:
- All menus, buttons, and interface labels
- Item names and descriptions
- Skill names, descriptions, and requirements
- Monster names and card descriptions
- Kafra NPC dialogue and services
- Chat system messages
- Equipment stats and item bonuses
- Navigation and map names
- Crafting, refining, and trading windows
- Status effects and buff descriptions

How it works:
The extension runs automatically when you visit play.midgardidle.ro. Translation starts immediately on page load. Use the extension popup to toggle translation on or off at any time.

Please note that some parts of the game may still appear in Portuguese or contain translation errors. The game is large and constantly updated, so the translation is an ongoing work in progress - new content is being added and improved regularly.

No data is collected. No accounts required. Works entirely in your browser.


--------------------------------------------------------------------------------------------------


Manual installation (without Chrome Web Store):

1. Download the ZIP file from the releases page
2. Unzip the file to any folder on your computer
3. Open Chrome and go to chrome://extensions
4. Enable "Developer mode" using the toggle in the top right corner
5. Click "Load unpacked"
6. Select the unzipped folder
7. The extension is now active - open play.midgardidle.ro and enjoy the game in English
